# Mac Pulse 1.5.0

- **Insights:** see sustained resource findings with links to the relevant app or chart, plus pressure, swap, available disk and Mac Pulse's own usage.
- **Storage growth:** track folders with local snapshots, compare complete scans and use a clickable storage map. Partial scans cannot produce misleading growth comparisons.
- **Alert rules:** configure thresholds, duration and optional app selection, including low disk space, memory pressure and CPU temperature. Set quiet hours for notifications.
- **Cleanup History:** inspect receipts and restore tracked items still in Trash. Restore verifies identity and the original folder and never overwrites existing files. Protected Trash locations or original folders may require Full Disk Access; denied access is explained and leaves the item in Trash.
- **App files:** review an app bundle and exact bundle-ID matches for caches, preferences, support data and saved state. Associated files require explicit selection and removal rechecks activity and file identity.
- **Connectivity:** run DNS, latency, packet-loss and HTTPS checks on demand.
- **Keep readings visible:** enable independent menu-bar items and a movable floating dashboard from Settings → Menu Bar.

Folder scans and network checks run only when requested. History and preferences stay local. Existing app settings and monitoring/Cleanup history are retained.

Requires an Apple Silicon Mac running macOS 14.2 or newer. This build uses free ad hoc signing and is not Apple-notarized; macOS may require approval for the first downloaded installation.
