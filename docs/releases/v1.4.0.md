# Mac Pulse 1.4.0

- Mac Pulse now checks for updates daily and offers a native update dialog with release notes, Install, Later and Skip options.
- Check manually from the Mac Pulse app menu, the menu-bar panel or Settings → Updates.
- Settings → Updates lets you disable automatic checks or opt in to automatic downloads and installation.
- Update feeds and downloads are signed and verified before extraction. Monitoring and cleanup data are never sent with update checks.
- Your existing settings, monitoring history and Cleanup state are retained.

**One-time upgrade:** versions 1.3.1 and earlier do not contain the updater. Quit the earlier app, download this release and replace it in Applications once. Subsequent releases can update inside Mac Pulse.

Requires an Apple Silicon Mac running macOS 14.2 or newer. This build uses free ad hoc signing and is not Apple-notarized; macOS may require approval for the first downloaded installation.
