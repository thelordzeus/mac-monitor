# Mac Monitor 1.0.0

The first release of Mac Monitor, a native macOS dashboard for live system statistics.

## Downloads

- **Mac-Monitor-arm64.dmg** — recommended installer for Apple Silicon. Open it and drag Mac Monitor to Applications.
- **Mac-Monitor-arm64.zip** — the same application bundle in a ZIP.
- **SHA256SUMS** — checksums for both downloads.

Requires an Apple Silicon Mac and macOS 14.2 or later. This build is locally signed and is not notarized by Apple. See the README for first-launch instructions.

## Included

- Ten tabs: Overview, CPU, Memory, Disk, Network, GPU, Battery, Sound, Bluetooth and Projects.
- Real system readings, grouped app/process rankings, temperatures and fan speeds where available.
- Menu-bar readouts and a compact panel that closes when you click outside it.
- Local history for up to 30 days, per-app history, activity alerts and optional notifications.
- App search and pinning, configurable layout and units, CSV and PNG exports.
- System output selection and per-app audio mixing through Core Audio process taps.
- Project grouping, listening ports and confirmed process termination.

## Validation and limits

The release build passed controlled single-core CPU, 256 MiB memory, 8 MiB TCP and 8 MiB disk tests, weighted/pending history checks, process grouping, stale-PID protection, app ranking and CPU scale checks. Seventeen comparisons with independent macOS counters passed on an Apple M4 Mac. See [the verification report](https://github.com/thelordzeus/mac-monitor/blob/main/docs/VERIFICATION.md) for measurements and limitations.

The release includes the memory-reservation, CPU averaging, ranking, history and pause/resume corrections from that audit. All ten dashboard views were rendered from real readings. The DMG is checked with `hdiutil verify`; the packaged app signature is checked with `codesign --verify --deep --strict`.

Per-app audio mixing needs macOS permission and has not been tested end to end. Battery and Bluetooth readings depend on the hardware. Manual fan control, a complete localization set and separate draggable menu-bar items are not included.
