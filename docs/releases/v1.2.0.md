# Mac Pulse 1.2.0

Mac Monitor is now **Mac Pulse**: native system monitoring and cleanup in one
macOS app. The new name appears in the app, menu-bar panel, settings, permission
messages, exports and installers.

- Watch live CPU, memory, GPU, disk, network, battery and app statistics.
- Review caches/developer files, explore storage and use the integrated
  app recovery, duplicate/media and AI/project tools.
- The README now gives monitoring and cleanup their own feature sections and
  inline screenshots, followed by installation and usage instructions.
- Existing history, settings, Cleanup state and the app's bundle identity are
  preserved. Quit Mac Monitor before opening Mac Pulse.

Download `Mac-Pulse-arm64.dmg` or `Mac-Pulse-arm64.zip`. The Apple Silicon build
requires macOS 14.2 or newer. It is locally signed (ad hoc), not Apple-notarized.
Media export requires an existing ffmpeg/ffprobe installation.

The source repository remains at https://github.com/thelordzeus/mac-monitor.
