# Mac Pulse 1.2.1

Fixed the three-dot action menus in Cleanup → Inventory. They now use native
macOS menus with the same ellipsis appearance and standard accessibility,
selection and dismissal behavior. The shared dropdown presentation layer is
also attached to the Cleanup workspace, so menus appear in its other tools.

App removal still opens its review/confirmation before any files are moved.
Selecting an Inventory action closes the menu; clicking outside or pressing
Escape dismisses it too.

Download the updated DMG or ZIP and replace the earlier app. Existing history
and settings are retained. The Apple Silicon build requires macOS 14.2 or newer
and is locally signed (ad hoc), not Apple-notarized.
