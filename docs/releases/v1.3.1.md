# Mac Pulse 1.3.1

Cleanup now consistently uses Mac Pulse naming throughout its code, modules,
components and documentation. Removed unused external product links and brand
assets from the component metadata. Required third-party copyright and license
text remains in the bundled `ThirdPartyNotices.txt` file.

The cleanup tools and review flow are unchanged. Existing settings and history
are retained. Download the updated DMG or ZIP and replace the earlier app.

The Apple Silicon build requires macOS 14.2 or newer and is locally signed
(ad hoc), not Apple-notarized.
