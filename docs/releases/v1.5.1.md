# Mac Pulse 1.5.1

- The top navigation now adapts to the window width. Wide windows show every tab label; narrower windows use compact icon tabs while keeping the selected tab's name visible.
- All tabs remain accessible without cut-off labels or horizontal scrolling. Hover over a compact tab to see its name, or use the All tabs menu.
- Custom tab order and hidden tabs are preserved. Exported dashboard images use the same adaptive navigation.

The seven features introduced in 1.5.0 remain included. Existing settings, monitoring history and Cleanup state are retained.

Requires an Apple Silicon Mac running macOS 14.2 or newer. This build uses free ad hoc signing and is not Apple-notarized.
