# Mac Pulse 1.2.2

Removed the BlitzClean integration credit card from Cleanup → Setup and the
"powered by BlitzClean" text from the Cleanup header. Setup now focuses on
permissions and project folders. Attribution remains in the repository
documentation and the license bundled with the app.

Download the updated DMG or ZIP and replace the earlier app. Existing history
and settings are retained. The Apple Silicon build requires macOS 14.2 or newer
and is locally signed (ad hoc), not Apple-notarized.
