# Mac Pulse 1.5.2

- Removed the Insights and Connectivity tabs to simplify navigation. System readings, pressure indicators and configurable alert rules remain available in the dashboard and Settings.
- Removed the unused Insights processing and on-demand connection-check code.
- Existing tab layouts retain their order and hidden-tab choices for the remaining tabs. Retired tabs are ignored when loading older preferences.
- Updated the README and monitoring screenshots to show the current navigation.

Existing monitoring history, storage snapshots, alert rules and Cleanup state are retained.

Requires an Apple Silicon Mac running macOS 14.2 or newer. This build uses free ad hoc signing and is not Apple-notarized.
