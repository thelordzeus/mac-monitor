# Mac Pulse 1.3.0

Inventory's Caches section now supports bulk cleanup directly from the list:

- Select individual caches with checkboxes or select all matches for a search.
- See associated app names and installed app icons, including apps that are closed.
- Review the selected count, size and exact cache paths before moving them to Trash.
- Keep running-app caches, open files, links and changed/unverifiable caches with
  an explanation. Automatic cleanup's existing age rules are unchanged.

Manual Inventory cleanup is recoverable through Trash. Space is reclaimed when
you empty Trash. Unidentified/tool caches use a neutral icon.

Download the updated DMG or ZIP and replace the earlier app. Existing history
and settings are retained. The Apple Silicon build requires macOS 14.2 or newer
and is locally signed (ad hoc), not Apple-notarized.
