# Mac Monitor 1.1.0

Mac Monitor now includes a native Cleanup workspace powered by BlitzClean's
MIT-licensed engines, using the app's dark theme, rounded cards and tab bar.

- Review old caches/reports, reinstallable developer dependencies, generated
  builds, simulators, Docker rebuildable storage and merged Git worktrees.
- Browse folders/drives, inspect storage inventory and review large files.
- Verify exact duplicates and export smaller media copies while keeping originals.
- Check app health and use app recovery, reviewed force quit, AI-worker controls
  and development-project pause/resume/start/stop tools.
- Open Cleanup with Command-Shift-K or from the menu-bar dashboard.
- Optional setup for Full Disk Access, Accessibility and extra project folders.

Cleanup remains local. The landing page waits for a tool/review to be opened.
Removal requires review and revalidation. Personal-file removal uses Trash;
eligible caches/developer artifacts are removed permanently after confirmation.
Docker containers and volumes remain protected. The host collector supplies
system stats, and existing tab order is preserved when adding Cleanup.

Media export needs an existing ffmpeg/ffprobe installation. Those tools are not
bundled or installed automatically. Permission and scan-budget limits are shown
in the interface.

Validation: release build/signature checks, temporary-file and mocked-driver
cleanup tests, host statistics/history self-tests, and native UI inspection.
Three real FFmpeg export checks are conditional and were skipped on the build Mac.
See [cleanup verification](https://github.com/thelordzeus/mac-monitor/blob/main/docs/CLEANUP-VERIFICATION.md).

The arm64 DMG/ZIP requires macOS 14.2 or newer and is locally signed (ad hoc).
It is not Apple-notarized. Installation instructions and SHA256 checksums are
included with the release.
